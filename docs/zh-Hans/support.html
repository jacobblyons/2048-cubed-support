发现 bug？有想法？

最快的联系方式是在 GitHub 上提交 issue。欢迎 bug 报告、功能建议和规则疑问。告诉我们发生了什么，以及你期待的结果。

常见问题

层是怎么运作的？ 三层 4×4 叠成一个方块。向左、右、上、下滑动会同时移动所有层。在屏幕上向下滑动会让每个方块落到下一层；相同的方块相遇时合并，不论在同一层还是层与层之间。

分数如何计算？ 每次合并累加其数值。拼出 2048 时，总分乘以步数加成（步数越少越高）和速度加成（玩得越快越高）。输掉的一局只保留合并得分。

红色光晕是什么意思？ 一层越满，边框越红。满了且无法合并时，游戏结束。

我的分数存在哪里？ 最高分列表保存在你的设备上。登录 Game Center 可把最高分放上全球排行榜。

我买了“移除广告”，广告却又回来了。 打开菜单右上角的圆盘，点击“恢复”。购买与你的 Apple ID 绑定。

我倾斜手机时方块会动。 这是陀螺仪视差效果。想让它静止，可在设置中关闭。
