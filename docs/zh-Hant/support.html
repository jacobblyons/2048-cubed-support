發現 bug？有想法？

最快的聯絡方式是在 GitHub 上提出 issue。歡迎 bug 回報、功能建議和規則疑問。告訴我們發生了什麼，以及你期待的結果。

常見問題

層是怎麼運作的？ 三層 4×4 疊成一個方塊。向左、右、上、下滑動會同時移動所有層。在螢幕上向下滑動會讓每個方塊落到下一層；相同的方塊相遇時合併，不論在同一層還是層與層之間。

分數如何計算？ 每次合併累加其數值。拼出 2048 時，總分乘以步數加成（步數越少越高）和速度加成（玩得越快越高）。輸掉的一局只保留合併得分。

紅色光暈是什麼意思？ 一層越滿，邊框越紅。滿了且無法合併時，遊戲結束。

我的分數存在哪裡？ 最高分列表保存在你的裝置上。登入 Game Center 可把最高分放上全球排行榜。

我買了「移除廣告」，廣告卻又回來了。 打開選單右上角的圓盤，點一下「恢復」。購買與你的 Apple ID 綁定。

我傾斜手機時方塊會動。 這是陀螺儀視差效果。想讓它靜止，可在設定中關閉。
